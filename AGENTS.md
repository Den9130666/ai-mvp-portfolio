# Agent instructions
- This repository contains demonstration MVPs, not production services.
- Keep demo behavior truthful: do not describe rules as AI or manual entry as OCR.
- Never commit credentials, API tokens, customer documents or real personal data.
- Keep dependencies minimal and document how to reproduce results.
- Validate inputs, escape user-controlled HTML, test errors and mobile layouts.
- Require human approval for outbound actions and irreversible operations.
