# AutoImport

Interactive import budget estimate using user-entered vehicle price, delivery, customs payments, service fee, other costs and reserve percentage. Includes cost breakdown, proportional bars, saved scenarios, reload and CSV export.

All values are manual estimates. No real customs tariffs, exchange rates, government fees or external integrations are used. The results are not a customs declaration or commercial quote. Data stays in browser localStorage.

Live: https://portfolio.omniq.space/autoimport/
